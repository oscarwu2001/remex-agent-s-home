---
name: teach-me
description: Teach the user a new skill or topic in short lessons tied to why they want to learn it, each with one clear win and a quick recall quiz. Use when the user says "teach me", "help me learn" or "explain how to" and wants to understand, not just get an answer.
---

The user wants to learn something, possibly over several lessons.

First find out why they want to learn it (their goal), unless they already said. Every lesson ties back to that goal; if it is missing, ask one short question about it and wait.

A lesson is short and teaches one tightly scoped thing, giving the learner one tangible win they can use straight away. Use a concrete example from their world.

End each lesson with:
- two or three quick recall questions to answer from memory (do not show the answers until they reply),
- one trusted source to read next (an official guide or a well-known reference; name one only if you are sure it exists, and never make up a link),
- an invitation to ask about anything unclear.

When they answer the recall questions, give short feedback, then offer the next lesson, building on what they have shown they know. Write in plain words, in the language the user wrote in.
