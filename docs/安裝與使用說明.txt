Agent's Home 安裝與使用說明
==========================

Agent's Home 會把你電腦上正在跑的 Claude（Claude App 的 Code 分頁）畫成一間醫院裡的人物。你可以一眼看到 Claude 在做什麼、什麼時候輪到你，以及用了多少 token。
它只讀取這台電腦上的 Claude 紀錄，不會修改你的檔案，也不會把資料傳到網路上。


【一、安裝】

1. 雙擊 AgentsHome-Setup-0.1.0.exe。
2. 如果出現「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。
   （這個安裝檔還沒有數位簽章，所以 Windows 會提醒，這是正常的。）
3. 照安裝畫面按下一步直到完成。桌面會出現「Agent's Home」捷徑。

不想安裝的話，也可以直接執行 AgentsHome-Portable-0.1.0.exe。


【二、第一次打開：設定三件事】

按右上角「Agent's Home」標題旁的齒輪圖示（設定）：

1. 語言：如果畫面是英文，選「繁體中文」。
2. 隱私與提醒 → 你的 Claude 方案：選你的方案（例如 Pro、Max 5×）。
   Agent's Home 看不到你的方案，要你自己選一次。
3. 代理與報告 → Claude 辦公室團隊（選用）：勾「圖面紀錄助手」，按「加入勾選的項目」。
   其他項目先不要勾，「團隊提醒」也先不要開。


【三、主畫面】

醫院地圖：
- 每個 Claude 對話是一個人物，Claude 叫出來的小幫手也會出現在各個房間。
- 人物頭上的泡泡代表狀態，例如「工作中」、「輪到你了」、「需要核准」。沒有泡泡表示正在思考。
- 拖曳可以旋轉，滾輪可以縮放，按一下房間就會移過去。

右邊的看板：
- 執行中：現在有幾個對話在跑。
- 等你處理：哪些對話在等你回覆。
- Claude Code 用量：用了多少 token。
- 需要留意：Agent's Home 讀不到或不確定的東西會列在這裡。


【四、迷你視窗（建議一直開著）】

按地圖上方的「迷你視窗」。它會浮在其他視窗上面；按圖釘可以取消。

最上面固定顯示三行：
- 上下文：目前這個對話用了多少。出現「上下文快滿了，請先儲存」時，請先把工作存好，因為 Claude 很快會自動壓縮對話。
- 5 小時、7 天：這台電腦上的 Claude Code 用了多少 token。
  碰到兩次用量上限之後，這裡會多顯示「約 xx%」的估計。

下面有兩個分頁：
- 現在：正在跑的對話和它們的待辦事項。
- 專案：你的專案清單。

精確的用量上限請看：Claude App → 設定 → 用量。


【五、隱私模式】

預設會隱藏檔案名稱、命令和待辦內容，只顯示數量，分享螢幕時比較安全。
想看細節的話：設定 → 隱私與提醒 → 取消勾選「隱藏檔案名稱、命令、問卷答案和 LINE 聊天」。


【六、圖面紀錄助手：記錄你怎麼檢查圖面】

1. 打開 Claude App，切到「Code」分頁。資料夾每次都選 OneDrive\圖面檢查。
   （剛加入助手的話，請開一個新的對話。）
2. 照平常一樣把截圖或 PDF 拖進對話，請 Claude 幫你檢查。
3. 檢查完，輸入「幫我記錄這次」或「記錄一下」。Claude 會給你一頁草稿：
   檢查了什麼、圖面慣例（規則加上例子）、你是怎麼問的、你修正了哪些地方。
4. 哪裡不對就直接說要改什麼。沒問題就回「好」，才會存到「圖面檢查\紀錄」資料夾。

紀錄裡會有零件名稱和編號，不會有圖片、客戶名稱，也不會存整段對話。
大約 20 份紀錄（或 3 週）之後，我們一起整理成 SolidWorks 圖面檢查助手。


【七、常見問題】

問：地圖上沒有人？
答：Agent's Home 只顯示 Claude App「Code」分頁裡的對話，一般聊天不會出現。請先在 Code 分頁開一個對話。

問：用量和 Claude App 顯示的不一樣？
答：Agent's Home 只計算這台電腦上的 Claude Code，你的方案上限還包含網頁版和手機的用量。準確數字以 Claude App → 設定 → 用量為準。

問：要怎麼移除？
答：Windows 設定 → 應用程式 → 找到 Agent's Home → 解除安裝。

有其他問題請直接問我。
