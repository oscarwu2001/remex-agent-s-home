# 圖面紀錄助手：使用說明

這三週請照平常的方式用 Claude 檢查圖面，檢查完說一句「幫我記錄這次」。累積大約 20 份紀錄後，我們一起整理成 SolidWorks 圖面檢查助手。

## 一、安裝（只要做一次）

1. 執行 `AgentsHome-Setup-0.1.0.exe`。如果 Windows 跳出「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」（這個安裝檔還沒有數位簽章）。
2. 打開 Agent's Home，按右上角的「設定」。
   - 畫面是英文的話：**語言** → 繁體中文。
   - **隱私與提醒 → 你的 Claude 方案**：選你的方案（Pro、Max 5× 等）。
   - **代理與報告 → Claude 辦公室團隊（選用）**：只勾「**圖面紀錄助手**」，按「加入勾選的項目」。「團隊提醒」先不要勾，這三週也先不要加其他助手，紀錄才會是你自己的習慣。
3. 按「迷你視窗」。迷你視窗上方會一直顯示：
   - **上下文**：目前對話用掉多少。快滿時會提醒你先儲存。
   - **5 小時**、**7 天**：這台電腦上 Claude Code 用了多少 token。

   精確的用量上限請看 Claude App → 設定 → 用量。

## 二、每次檢查圖面

1. 打開 Claude App，切到 **Code** 分頁。如果剛加了助手，請開一個新的對話。
2. 資料夾每次都選 **OneDrive\圖面檢查**。
3. 照平常一樣，把截圖或 PDF 拖進對話，請 Claude 幫你檢查。

## 三、記錄這次

1. 檢查完（或中途覺得值得記下來），輸入「**幫我記錄這次**」或「**記錄一下**」。
2. Claude 會給你一頁草稿，內容有：
   - 這次檢查了什麼；
   - 圖面慣例，每條是一條規則加上這次的例子；
   - 你是怎麼問的；
   - 你修正了 Claude 哪些地方。
3. 哪裡不對就直接說要改什麼。沒問題就回「**好**」，草稿才會存到 `圖面檢查\紀錄` 資料夾。沒說「好」就不會存。
4. 紀錄裡會有零件名稱和編號。不會有圖片、客戶或公司名稱，也不會存整段對話。

有問題請直接問我。
